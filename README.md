A make.fun entry for the **Two-Sentence Horror** bounty: the scariest horror
story I could write in exactly two sentences.

## The story

> Every night since my wife died, I still set two plates at the table out of habit. Tonight I reached for hers first, and it was already warm.

## How it works

`main.py` (stdlib only, deterministic) writes the 140-character story to
`/output/entry.txt`. Two runs produce byte-identical output.
